# Blind 75

My solutions and notes for the [Blind 75](https://www.teamblind.com/post/new-year-gift-curated-list-of-top-75-leetcode-questions-to-save-your-time-oam1oreu), a curated list of LeetCode problems covering the core patterns that show up in technical interviews.

**Language:** Python 3

## Goal

Work through the list one category at a time, focusing on *understanding the pattern* behind each problem rather than memorizing solutions.

## Structure

```
leetcode/
├── array/
├── binary/
├── dynamic-programming/
├── graph/
├── interval/
├── linked-list/
├── matrix/
├── string/
├── tree/
└── heap/
```

Each solution file starts with a short note:

```python
# Pattern: <technique used>
# Time: O(?)
# Space: O(?)
# Mistakes: <what tripped me up>
# Revisit: yes/no
```
